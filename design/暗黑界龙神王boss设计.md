## 0. 一句话概括

一个用“暗黑界卡污染手牌 + 弃置惩罚 + 回归回血”把玩家拖入资源战的三层超规格 Boss。  
核心不是把玩家打死，而是让玩家在 **保留 / 打出 / 消耗** 三种处理暗黑界卡的方式之间不断做错选择。

---

## 1. 定位与设计目标

### 1.1 定位

- **三层（Act 3）Boss**，超规格：比原版三层 Boss 高一档。
- 原因：本 mod 成型卡组裸输出可达 **300–400/回合**，不能按原版 Boss 的血量/伤害直接套。
- 默认走原版 `RoomType.Boss` 奖励流程（金币 + 卡牌 + Boss 遗物）；专属 Boss 遗物为可选扩展。

### 1.2 设计基准

| 项                            | 目标                       |
| ---------------------------- | ------------------------ |
| 玩家裸输出（成型卡组）                  | 300–400/回合               |
| 玩家受控输出（虚弱 + 手牌污染 + 洗脑 + 取引后） | **150–250/回合**           |
| 目标战斗长度                       | **5–8 回合**               |
| Boss 基础生命                    | **800**（高进阶 880；回归回血 50/张，有效生命取决于玩家是否屯牌） |
| 玩家获胜时的剩余生命                   | 30–50%（打得好）              |

### 1.3 核心体验

1. Boss 把暗黑界攻击卡塞进玩家牌堆；这些卡 **1 费 / 保留 / 高伤害**，但打出会给回归送血，留着会占手牌位。
2. 玩家每回合第一次“主动/被强制”弃牌会触发 Boss 被动，按弃置牌类型给 Boss 不同收益。
3. 回归吸收暗黑界卡回血；玩家最好的节奏是 **回归前屯住 → 回归后倾泻**。
4. 取引在回归后的倾泻窗口打断玩家；洗脑在回合边界补状态压力。
5. 玩家的反制：消耗暗黑界卡、屯牌卡回归、人工制品/净化断 debuff、在控制压死前用 300–400 的输出抢杀。

### 1.4 非目标

- 不是纯数值墙：不能只靠 800 血 + 回血拖时间。
- 不是纯 RNG 秒杀：取引/军神的随机要有可操作的预防手段。
- 不依赖单一解：不能“没有消耗/没有人工制品就必死”。
- 不让“不弃牌 combo”完全绕过 Boss 机制（见 §7 风险与 §5 顺序 C）。

## 3. 核心机制

### 3.1 被动：暗黑界的诱惑（关键词）

#### 触发规则（最终版）

- **每玩家回合的第一次弃置**触发；**回合结束的手牌清理不触发**。
- 玩家回合开始时重置“本回合是否已触发”。
- 一次弃置多张时，以 **弃牌顺序的第一张** 定类型。
- 由敌方效果造成的强制弃置（如取引）也算玩家的弃置；若玩家本回合已经弃过牌，则不再触发。
- 触发时依次结算：
  1. 被弃置卡牌自身的“从手牌被弃置时”效果（如果是暗黑界攻击卡）。
  2. 按第一张牌的类型结算被动分支。
  3. 将 **1 张随机暗黑界攻击卡** 洗入玩家抽牌堆。
- 如果玩家回合结束手里全是保留卡、没有弃置，则不触发（合理：玩家已经付出了手牌位）。
- 被动是 **可规避的**：玩家可以通过“不弃牌”减少触发；取引会强制触发（如果本回合还没弃过）。这是设计意图——惩罚弃牌，而不是无条件每回合触发。

#### 分支表

| 第一张弃置牌类型              | 效果                        |
| --------------------- | ------------------------- |
| 攻击                    | 龙神王获得 **2 点力量**           |
| 技能                    | 将 **1 张「暗黑界的洗脑」** 洗入玩家抽牌堆 |
| 能力                    | **随机弃置玩家 2 张手牌**          |
| 其他（状态 / 诅咒 / 其他自定义类型） | 将 **1 张同名牌** 洗入玩家抽牌堆      |
| **每次触发额外**            | 将 **1 张随机暗黑界攻击卡** 洗入玩家抽牌堆 |

#### 设计意图与风险

- 攻击/技能是主要分支；设计假设约 **50/50**。
- 玩家可以控制第一张弃牌 → 会“择优”。如果大卡组 + 堆墓把洗脑稀释得太厉害，玩家会尽量选技能分支，攻击分支的 +2 力量可能永远不触发 → Boss 的伤害成长线消失。
- 测试时记录“玩家可自由选择”和“随机弃置”两种情况的分布。如果技能分支 >80%，给洗脑状态加即时代价（抽到时失去 2–3 生命，或失去 1 能量），让两条分支的“痛感”接近。
- 能力分支因为结束清理不触发，只会发生在主动/强制弃置的回合中段，随机弃 2 是有意义的。
- 其他分支是“安全但污染”：用一张状态/诅咒换掉 +力量/洗脑，但会慢慢复制诅咒。玩家有诅咒时可以用它躲开更痛的分支，这是合理的取舍。
- **UI**：做成关键词「暗黑界的诱惑」，悬浮显示四种分支 + 额外塞卡；在将触发被动的那张牌上加一个 Boss 标记/描边。

### 3.2 行动循环（推荐版本：B 顺序）

六个动作固定循环：

> **雷 → 军势 → 登极 → 回归 → 取引 → 洗脑**

#### 第一轮节奏（B = Boss 回合，P = 玩家回合）

| 回合 | 动作     | 效果                                             |
| -- | ------ | ---------------------------------------------- |
| B1 | 暗黑界之雷  | 10×3 = 30 伤害（A8 12×3）；施加 3 易伤 + 3 虚弱；玩家 P2 开始 -25% 输出 |
| B2 | 暗黑界的军势 | 13 伤害（A8 14；雷还剩 2 易伤 → 19/20）；3 张随机暗黑界诅咒卡洗入玩家抽牌堆 |
| B3 | 暗黑界的登极 | 39 伤害（A8 43；雷还剩 1 易伤 → 58/64）；第一次大招就吃到易伤         |
| B4 | 龙神回归   | 吸收抽牌堆 + 弃牌堆 + 消耗堆的暗黑界诅咒卡，每张回复 50 生命；被吸收的卡移出战斗 |
| P5 | （玩家）   | 雷的 3 层在本回合开始前刚好掉完 → **干净倾泻窗口**                 |
| B5 | 暗黑界的取引 | 施加 5 虚弱 + 5 易伤；生成 2 张随机暗黑界诅咒到手牌，然后弃置手牌中所有暗黑界诅咒 |
| B6 | 暗黑界的洗脑 | ceil(当前回合/2) 张「暗黑界的洗脑」洗入玩家抽牌堆；第一次（B6）为 3 张 |

#### 为什么是这个顺序

1. **雷放第一**：玩家第 2 回合开始就 -25% 输出，压住 300–400 的早期 combo。
2. **军势放登极前**：3 张暗黑界卡在登极前污染手牌，降低玩家挡 58 的能力。
3. **登极吃到易伤**：39×1.5≈58，第一次大招就有威胁。
4. **回归在中段**：50/张是中期续航，不是重置；回归后 P5 是玩家干净倾泻窗口。
5. **取引在 P5 后**：5/5 接管覆盖，并把玩家的倾泻窗口打断。
6. **洗脑收尾**：状态在下一轮雷之前进牌堆，形成“状态 + 雷”的回合边界压力。
7. **3+5 覆盖不断档**：雷 3 撑到登极，取引 5 撑到下一轮雷；P5 的干净窗口是有意留的“呼吸 + 倾泻”回合。

#### 备选顺序

| 方案          | 顺序                         | 定位                                               |
| ----------- | -------------------------- | ------------------------------------------------ |
| **B（推荐）**   | 雷 → 军势 → 登极 → 回归 → 取引 → 洗脑 | 早期虚弱压 combo、登极吃易伤、P5 干净窗口、取引打断                   |
| **A（最小改动）** | 军势 → 雷 → 登极 → 回归 → 取引 → 洗脑 | 保留军势开局主题；第一次登极吃易伤；但 P2 无虚弱，对“第一回合就成型”的 combo 偏慢  |
| **C（最强控制）** | 取引 → 军势 → 登极 → 回归 → 雷 → 洗脑 | 第 1 回合抽 2 弃 2 + 5/5；登极吃易伤；雷第 5 回合续覆盖；开局最压，注意慢速卡组 |

**实测决策**：先用 B。如果“不弃牌 combo”仍能在 P3 前杀，改 C 或基础血 1000–1200；如果 B 下慢速卡组活不过第一轮，回 A 或降低取引/雷的覆盖。

### 3.3 状态牌：暗黑界的洗脑

| 项           | 值                                                                |
| ----------- | ---------------------------------------------------------------- |
| 费用          | 0                                                                |
| 类型          | 状态                                                               |
| 关键词         | 消耗                                                               |
| 触发          | 抽到时自动打出                                                          |
| 效果          | 获得 1 层「洗脑」debuff：打出的下一张牌无效                                       |
| 叠加          | 多层可叠加；每层吞掉一张牌；跨回合保留                                              |
| 打出判定        | 自动打出算“打出”；手动打出也算；被弃置按原版不算“打出”                                    |
| 自动打出是否算“打出” | 算（触发通用“每打出 X 张牌”收益；不算技能/攻击/能力类型触发）                               |
| 无效判定（建议）    | 费用照付；牌算“打出”（触发“打出时”通用收益）；进弃牌堆；伤害/格挡/效果被无效化                       |
| UI          | 向 Act 1 Boss「仪式兽」的眩晕 debuff 靠拢：图标 + 层数 + 抽到时的明显提示；悬浮「被洗脑：下一张牌无效」 |

**数量**：洗脑动作 = ceil(当前回合/2)：第一次（B6）3 张，第二次（B12）6 张，长局继续增长；诱惑的技能分支每次额外 1 张。大卡组 + 堆墓稀释后实际触发约 2–3 次。真正要小心的是大抽牌回合一次抽到多张 → 直接吞掉一个 combo 回合。

### 3.4 暗黑界四神将（Boss 塞给玩家的攻击卡）

全部为 **1 费 / 诅咒 / 保留**；战斗内临时加入抽牌堆或手牌，战斗结束移除；打出时对自己的主人造成伤害，进弃牌堆（可被回归吸收）。

| 卡名     | 费用 | 自伤 | 保留 | 从手牌被弃置时            |
| ------ | -- | -- | -- | ------------------ |
| 暗黑界的鬼神 | 1  | 12 | 是  | 对自己造成 12 点伤害（可格挡）  |
| 暗黑界的斗神 | 1  | 8  | 是  | 龙神王获得 3 点力量        |
| 暗黑界的军神 | 1  | 11 | 是  | 随机将 2 张手牌洗入抽牌堆     |
| 暗黑界的武神 | 1  | 11 | 是  | 对自己施加 1 层虚弱和 1 层易伤 |

#### 威胁梯度（从高到低）

**斗神（+3 力量，永久成长） > 武神（补 debuff） > 军神（洗牌/反屯牌） > 鬼神（可格挡的 12 自伤）**

- 玩家会优先处理斗神、留下鬼神；这个取舍是清晰的。
- 军神不只是干扰：把 2 张手牌洗回抽牌堆，如果洗到的是玩家屯的暗黑界卡，它们就从“手里安全区”变成“回归可吸收区”——**军神是反屯牌的**。
- 斗神 +3 力量如果被取引弃到，再触发被动攻击分支 +2，一回合可能 +5 力量；对 10×3 的雷很致命。

#### 关键交互

- 四张卡都「保留」→ 不会在回合结束被弃掉，会长期占手牌位。玩家必须选择：留着（手牌变窄，回归回血少）、打出（1 费 + 自伤，牌进弃牌堆给回归送血）、消耗（最优解，但需要卡位/费用）。
- 鬼神自伤可格挡：有格挡的回合它是最安全的弃置对象。
- 暗黑界卡被弃置时，先结算自身效果，再结算被动分支，再塞 1 张暗黑界攻击卡。

### 3.5 暗黑界的侵蚀（v0.6.4）

- **战斗开始时**：将 2 张随机暗黑界诅咒直接置入每名玩家的手牌（高进阶 3 张）。这是手牌，不是抽牌堆；开局抽牌后玩家会看到 7/8 张起手。
- **弃置计数**：每名玩家独立累计“从手牌弃置”的牌数；每满 2 张，就将 1 张随机暗黑界诅咒置入其手牌，余数保留（弃 3 张 → 1 张 + 余 1；再弃 1 张 → 再 1 张）。
- **不触发**：回合结束的手牌清理不算；弃光（抽牌堆→弃牌堆）不算，只认 `CardCmd.Discard` 的手牌弃置。
- **满手**：手牌已 10 张时，生成的诅咒改为进入弃牌堆，避免撑坏手牌 UI。
- **定位**：把“弃牌”从一次性的诱惑触发，变成持续的手牌税；起手 2 张保证快攻卡组第一回合就感受到污染，而不是 3 回合杀完都没抽到军势的诅咒。

## 4. 数值与平衡

### 4.1 血量与有效血量

- 基础生命：**800**（高进阶 880）。
- 回归回血：50/张，无上限，但受最大生命限制（满血时只吸收不回血）。
- 回复速率：被动 1 张/回合（若玩家弃牌）+ 军势 3 张/6 回合 = **1.5 张/回合 × 50 = 75 生命/回合**（玩家不阻止的情况下）。
- 有效血量：800 基础 + 实际回血；玩家可以用“屯手牌”把回归压到 0，所以有效血量方差很大。
- v0.6.4 的加强走的是“起手 2/3 张诅咒 + 每弃 2 张塞 1 张”的手牌压力，而不是提血量；如果实测仍能在 3 回合杀，再按调参开关提血。

#### 调参开关

| 现象           | 调整                              |
| ------------ | ------------------------------- |
| 成型卡组在 P3 前击杀 | 基础血提到 **1000–1200**，或改用 C 顺序    |
| 战斗 >10 回合    | 降低控制（洗脑/取引覆盖）或降低血量，不要只加血        |
| 受控输出 <100    | Boss 会变成回血墙：降低 75/回合的回复速率，或减少塞卡 |
| 受控输出 >250    | 战斗 3–4 回合，回归还没出来就结束：提血或 C 顺序    |

### 4.2 回归（龙神回归）

| 项     | 规则                                                                         |
| ----- | -------------------------------------------------------------------------- |
| 吸收范围  | 玩家 **抽牌堆 + 弃牌堆 + 消耗堆** 的所有暗黑界诅咒卡；**不吸收手牌**（手牌是安全区，屯牌是玩家的反制）                      |
| 回血    | 每张 **50**；无上限；不超过最大生命                                                      |
| 被吸收的卡 | **移出战斗**，不进入消耗堆（不触发“消耗时”收益，也不会被“从消耗堆回收”利用）                                 |
| 0 张时  | 建议仍然使用（回 0，但吸收 = 没有），作为玩家成功反制的奖励；如果觉得空放太蠢，可以给 5 格挡或跳过改登极（待定）               |
| 意向显示  | 建议显示“预计回复 X”（当前抽牌堆 + 弃牌堆 + 消耗堆的暗黑界卡数 ×50），让玩家能规划                                 |
| 单次上限  | 无上限；v0.6.4 起手 2 张 + 军势 3 张 + 侵蚀持续塞卡，单次回归的理论回血更高；实际会被“屯手牌/消耗/回归前打掉”削减 |

**回归的定位**：50/张是当前值，回归是中期续航而不是重置；玩家 300–400 的输出有机会抢杀。如果实战出现“一口回 250+ 把战斗拖到 10 回合”，再降到 40/张或加软上限。

### 4.3 易伤/虚弱覆盖（雷 3 + 取引 5）

- 易伤/虚弱是二元乘区，层数 = 持续时间。
- 雷 3 层 + 取引 5 层 = 8 层/6 回合循环；玩家在第一次雷之后基本全程覆盖，**P5 是唯一干净窗口**（雷的 3 层刚好掉完，取引还没上）。
- 人工制品/净化是断档手段：一次人工制品只挡一次 debuff 应用；雷和取引各上“虚弱 + 易伤”，一个循环 4 次应用。要挡出完整窗口（虚弱和易伤都断），至少需要 2 层挡住取引的两个 debuff，或者用净化。
- 设计意图：5/5 不是“数值过载”，而是把 300–400 的输出压到 225–300（虚弱），再用登极/雷的 58/45 制造伤害压力；玩家用人工制品/净化/快速击杀来破局。
- 如果测试发现“没有人工制品的卡组必死”，检查 mod 里人工制品/净化的密度；如果密度太低，考虑给玩家更多来源，或把取引的 5/5 降到 4/4（但会牺牲覆盖，需重算）。

### 4.4 玩家输出与回合数

| 项                       | 数值               |
| ----------------------- | ---------------- |
| 裸输出基准                   | 300–400/回合（成型卡组） |
| 虚弱 -25% 后               | 225–300          |
| 手牌污染 + 洗脑 + 取引后（受控输出目标） | **150–250**      |
| 净推进（受控输出 - 75 回复速率）     | 75–175/回合       |
| 800 基础血                 | **4–8 回合**       |
| 加实际回血后的有效战斗             | **5–8 回合**       |

- v0.6.4 起手 2/3 张诅咒 + 每弃 2 张塞 1 张，会直接压低快攻卡组的“受控输出”（死牌占手牌位、打出要自伤/送回归），因此不再只靠提血来拖长战斗。
- 如果受控输出 >250：战斗 3–4 回合，回归还没出来就结束 → 提血到 1000–1200 或 C 顺序。
- 如果受控输出 <100：Boss 回血 > 玩家输出 → 降低控制/回复速率，或给玩家更多输出窗口。
- **测试核心指标是“受控输出”，不是裸输出。**

### 4.5 被动分支平衡

| 分支       | 强度    | 备注                                                                    |
| -------- | ----- | --------------------------------------------------------------------- |
| 攻击 +2 力量 | 长期成长  | 每次 +2，Boss 的成长线比旧版快一倍；10 回合理论 +20，雷从 30→90，登极 39→59（未计易伤）                    |
| 技能 +1 洗脑 | 中期税   | 大卡组 + 堆墓稀释后实际 2–3 次 nullify；每次 ≈ 1 张牌 + 能量；自动打出算打出，会推进玩家“打出计数”收益，部分抵消 |
| 能力 随机弃 2 | 爆发干扰  | 在主动/强制弃置的回合中段有意义；如果玩家手里有保留的暗黑界卡，可能直接弃到它们并触发效果——反屯牌                    |
| 其他 复制一张  | 安全但污染 | 玩家有诅咒时可以选它躲开 +力量/洗脑，但会慢慢复制诅咒                                          |




**50/50 是设计假设，不是强制分布。** 玩家可以控制第一张弃牌 → 会择优。如果技能分支 >80%，给洗脑加即时代价，或接受“固定招式 + 斗神”是主要伤害来源。

### 4.6 暗黑界四卡的威胁梯度

| 卡  | 威胁      | 原因                                          |
| -- | ------- | ------------------------------------------- |
| 斗神 | 最高      | +3 力量永久成长；被取引弃到再触发诱惑攻击分支 +2，可能 +5/回合                     |
| 武神 | 中       | 补 1 易伤/虚弱；在永久覆盖体系里只是延长 1 回合，玩家可能把它当“安全屯牌”对象 |
| 军神 | 中       | 洗 2 张干扰 + 反屯牌；洗到暗黑界卡会让下一轮回归吃它们              |
| 鬼神 | 低（有格挡时） | 12 自伤可格挡；玩家会优先弃它                            |

**玩家策略**：优先处理斗神，留下鬼神；军神看手牌决定打还是屯；武神在 debuff 快断时最危险。

## 6. 规则判定与交互（实现前必须钉死）

1. **被动的“弃置”**：只认主动/卡牌效果/敌方强制弃置；回合结束的手牌清理不触发；玩家回合开始重置；多张看弃牌顺序第一张。
2. **取引的强制弃置**：算玩家弃置；如果本回合还没弃过，触发被动；第一张随机弃牌决定分支；同时触发“额外塞 1 张暗黑界攻击卡”。玩家可以在自己回合先主动弃一张“选分支”，让取引不再触发被动。
3. **暗黑界卡自身的弃置效果 vs 被动**：先结算卡自身效果（如斗神 +3 力量），再结算被动分支，再塞 1 张暗黑界攻击卡。斗神作为第一张被弃置时，+3 +1 = +4 力量。
4. **弃置不算打出**：按原版，暗黑界卡被弃置不触发“打出时”收益；洗脑自动/手动打出算打出。
5. **洗脑 nullify**：建议费用照付、算打出、进弃牌堆、效果无效；多层叠加、跨回合；自动打出算打出（触发通用“每打出 X 张牌”收益，不算技能/攻击/能力类型触发）。
6. **回归吸收**：只吸收抽牌堆 + 弃牌堆 + 消耗堆的暗黑界诅咒卡；不吸收手牌；被吸收的卡移出战斗，不进消耗堆；回血 50/张，不超过最大生命；无上限。
7. **军神 → 抽牌堆 → 回归**：军神洗回抽牌堆的暗黑界卡，下一轮回归可以吸收并回血——军神是反屯牌。
8. **回归不走消耗堆**：检查 mod 的“离开弃牌堆”token 语义/触发，避免暗黑界卡被吸收时误触发玩家的收益；如果有，需要在吸收时打标记/排除。
9. **战斗内临时卡**：军势/被动塞的暗黑界卡、洗脑状态均为战斗内临时牌，战斗结束移除；不进永久卡组（按本设计假设；如果要做永久污染，数值另算）。
10. **多人**：所有随机（塞哪张暗黑界卡、取引弃哪两张、军神洗哪两张）必须用 `monster.Rng` / `RunRng`，不能用 `GD.Rand`，否则联机校验和断线。
11. **取引抽 2**：抽牌可能抽到洗脑（立刻自动打出并上 nullify）或暗黑界卡（随后可能被随机弃掉触发效果）——这是双刃剑，不是纯帮助。
12. **回归的“吸收”动画/顺序**：建议先显示吸收数量/回血预览，再结算回血；吸收的卡从抽牌堆/弃牌堆移除，不进入消耗堆。

## 7. 已知风险与对策

| 风险                 | 现象                                                    | 对策                                                |
| ------------------ | ----------------------------------------------------- | ------------------------------------------------- |
| **不弃牌 combo 绕过被动** | 被动不触发，Boss 只剩固定招式；300–400 输出 2–3 回合杀 800              | 用 C 顺序/取引开局；基础血 1000–1200；或给军势第一回合额外塞 1 张到手牌      |
| **被动分支被择优**        | 玩家永远弃技能，攻击分支 +2 力量不触发，伤害成长线消失                         | 给洗脑加即时代价（抽到失去 2–3 生命/1 能量）；或接受固定招式 + 斗神为主要伤害      |
| **取引最坏连锁**         | 手里 5 张暗黑界卡，抽 2 弃 2 弃到斗神 + 鬼神 → +3/+4 力量 + 12 自伤 + 5/5 | 玩家提前打出/消耗暗黑界卡；不要过度屯牌；测试是否有翻盘手段                    |
| **回归回血方差**         | 玩家堆墓/打出多张，回归一次回 250+                                  | 当前 50/张；若回血方差过大，降到 40/张或加“最多吸收 5 张”软上限（会牺牲无上限设计，慎用） |
| **人工制品依赖**         | 没有人工制品/净化的卡组被 5/5 永续覆盖压死                              | 确认 mod 里人工制品/净化密度；或提供其他清除手段；不要把 5/5 当成唯一解         |
| **大卡组稀释洗脑**        | 6 张洗脑实际只触发 2–3 次，技能分支变“安全”                            | 这是预期内的稀释；如果太安全，给洗脑加即时痛感                           |
| **光道堆墓喂回归**        | 玩家的堆墓把暗黑界卡送进弃牌堆，回归直接吃                                 | 设计意图（光道主机制被克制）；用回血预览/上限/测试确认不是“怎么打都送血”            |
| **回归 0 张空放**       | 玩家完全屯住/消耗，回归回 0                                       | 建议仍使用（玩家反制奖励）；或给 5 格挡/跳过（待定）                      |

## 8. 测试矩阵

### 8.1 卡组类型

1. 快速 combo（不弃牌、300–400 裸输出）
2. 慢速格挡/中毒
3. 光道堆墓/弃光（mod 主机制）
4. 无消耗（Exhaust）手段
5. 人工制品/净化密集
6. 大卡组（40–50 张）vs 薄卡组（20–25 张）

### 8.2 指标

- 击杀回合数、玩家剩余生命
- **受控输出**（实际每回合伤害，扣掉虚弱/格挡/无效牌）
- 暗黑界卡：塞入/抽到/打出/屯手/消耗/被回归吸收的数量
- 每次回归的实际回血量
- 洗脑抽到次数/nullify 次数
- 易伤/虚弱覆盖率（% 回合）
- 被动分支分布（攻击/技能/能力/其他）
- 取引最坏情况的结果
- 回归 0 张/满血时的表现

### 8.3 目标区间

- 战斗 **5–8 回合**；玩家剩 **30–50%** 生命（打得好）
- 受控输出 **150–250**
- 回归回血 **90–180**（前期）/ **180–300**（后期）
- 没有单一分支 >80%
- 不弃牌 combo 不早于 **P4** 击杀
- 无消耗卡组仍有机会（至少能靠屯牌/回归后倾泻赢）

### 8.4 必测最坏情况

- 起手 2 张暗黑界卡
- 取引弃到斗神 + 鬼神
- 回归前刚打出一波暗黑界卡
- 大抽牌回合一次抽到 3 张洗脑
- 手里屯 5+ 张暗黑界卡
- 回归时 0 张/满血
- 玩家用军神把暗黑界卡洗回抽牌堆后接回归

## 9. 实现要点

### 9.1 注册与素材

- 素材占位 ID：`dark_world_grapha`；路径见 `design\boss素材_暗黑界的龙神王\README.md`。
- `EncounterAssetProfile` 显式填 `BossNodeSpinePath`（PNG 前缀）+ `RunHistoryIconPath`/`Outline`；战斗立绘静态加载，参考圣女立绘的缩放/脚底贴地。
- 注册：`[RegisterMonster]` + `[RegisterActEncounter(typeof(三层 Act))]`；具体 Act 类型按工程现状填；Boss 池会自动追加。
- **Boss 发现顺序**：原版 3 Boss 都见过后，mod Boss 才会进随机轮换；调试用控制台 `fight <ENCOUNTER_ID>`。
- **奖励**：默认 `RoomType.Boss` 自动走原版奖励；专属 Boss 遗物（若做）按工程规范用 `RelicRarity.Boss`。

### 9.2 卡牌/状态池

- 四张暗黑界攻击卡和洗脑状态 **不进卡牌奖励池/商店/普通图鉴**（或单独 Boss 图鉴页），只作为战斗内临时牌；按 mod 现有卡池过滤机制处理，避免玩家在奖励里拿到。
- 洗脑是状态牌，不是可收集卡；战斗结束移除。

### 9.3 UI/提示

- 关键词「暗黑界的诱惑」：悬浮显示四分支 + 额外塞卡；行内只放金色标题 + 句号，详细规则放悬浮（按 mod 关键词规范）。
- 在将触发被动的那张牌上加 Boss 标记/描边；如果实现成本高，至少在 Boss 意图/关键词里说明“本回合第一次弃置将触发”。
- 回归意向显示“预计回复 X”；洗脑 debuff 图标 + 层数，向眩晕靠拢；抽到洗脑时给明显提示。
- 取引的意图显示 debuff/抽弃；军势显示“伤害 + 塞 3 张”；洗脑显示“塞 3 张状态”。

### 9.4 逻辑/兼容

- 多人：HP 自动缩放；所有随机用 `monster.Rng`/`RunRng`。
- 洗脑自动打出：抽到时自动消耗并上 debuff；算“打出”（通用触发），不算技能/攻击/能力类型。
- 取引强制弃置：若本回合未触发被动，则触发；随机第一张决定分支；额外塞 1 张暗黑界卡。
- 回归吸收：从抽牌堆 + 弃牌堆移除，不进消耗堆；检查 mod 的“离开弃牌堆”token 触发。
- 四张暗黑界卡：战斗内临时牌；打出后不消耗（可被回归吸收）；弃置效果仅在“从手牌被弃置”时触发。
- 实现后按项目发布流程跑 **memberref 审计** + **`LsCompatTrial` 试编译**；新怪物的反射/成员引用要过双版本。

## 附录 B：本地化文案（建议）

### B.1 Boss

- **名称**：暗黑界的龙神王 格拉法
- **被动关键词**：暗黑界的诱惑、暗黑界的侵蚀

**动作文案：**

- **暗黑界之雷**：造成 10 点伤害，重复 3 次（高进阶 12 点）。施加 3 层易伤和 3 层虚弱。
- **暗黑界的军势**：造成 13 点伤害（高进阶 14）。将 3 张随机暗黑界诅咒卡洗入玩家的抽牌堆。
- **暗黑界的登极**：造成 39 点伤害（高进阶 43）。
- **龙神回归**：吸收玩家抽牌堆、弃牌堆和消耗堆中所有暗黑界诅咒卡，每张回复 50 点生命。被吸收的卡移出战斗。
- **暗黑界的取引**：施加 5 层虚弱和 5 层易伤。生成 2 张随机暗黑界诅咒到手牌，然后弃置手牌中所有暗黑界诅咒。
- **暗黑界的洗脑**：将 ceil(当前回合/2) 张「暗黑界的洗脑」洗入玩家的抽牌堆（第一次 3 张）。

**被动悬浮描述：**

> 每回合第一次弃置卡牌时，根据第一张牌的类型触发：攻击→获得 2 力量；技能→塞 1 张洗脑；能力→随机弃 2 张手牌；其他→复制一张。然后塞 1 张随机暗黑界诅咒卡。回合结束的手牌清理不触发。

> **暗黑界的侵蚀**：战斗开始时，将 2 张随机暗黑界诅咒置入你的手牌（高进阶 3 张）。你每从手牌弃置 2 张牌，将 1 张随机暗黑界诅咒置入你的手牌。

### B.2 卡牌

- **暗黑界的鬼神**：1 费。打出时：对自己造成 12 点伤害。保留。从手牌被弃置时：对自己造成 12 点伤害。
- **暗黑界的斗神**：1 费。打出时：对自己造成 8 点伤害。保留。从手牌被弃置时：龙神王获得 3 点力量。
- **暗黑界的军神**：1 费。打出时：对自己造成 11 点伤害。保留。从手牌被弃置时：随机将 2 张手牌洗入抽牌堆。
- **暗黑界的武神**：1 费。打出时：对自己造成 11 点伤害。保留。从手牌被弃置时：对自己施加 1 层虚弱和 1 层易伤。
- **暗黑界的洗脑**：0 费。消耗。抽到时自动打出：获得 1 层「洗脑」（打出的下一张牌无效）。

> 多段伤害文本按项目规范使用官方句式（“造成 10 点伤害，重复 3 次”），不要写“10×3”。
